# ISMS 資安小鎮（遊戲式互動地圖）

不是影片播放：使用者自己點選想看的地方。阿拉蕾走過去、Allan 顧問跟在後面，到了就說明（配音）並打開任務卡。

製作：Allan Lo｜2026/10/16

## 玩法
- **逛小鎮**：12 棟建築＝ISMS 工作場域（顧問辦公室、人資大樓、文件圖書館、供應商港口、IT 服務台、資安指揮中心、機房、開發工坊、風險研究所、會議廳、稽核所、演練廣場），各自對應 15 項運作能力。
- **月份・頻率篩選**：有任務的建築冒出「!」，金色「★」表示當月有每年、半年或每季的重點工作；地圖季節隨月份變化。
- **流程路線**：新人到職、人員離職、系統變更、監控與資安事件、每月月報、年度 PDCA、供應商管理。地圖畫出路線，按「下一步」一站一站走。
- **任務卡與稽核準備度**：91 張任務卡（表單編號、使用時機、稽核必要、顧問建議），打勾累積準備度與徽章（存在瀏覽器本機）。
- **任務日誌**：地圖下方依篩選列出全鎮工作，點建築名稱就走過去。

## 修改
資料都在 `src/template.html`：`BLD`（建築與任務）、`FLOWS`（流程）、`LINES`（配音台詞）。

```
pip install edge-tts
python3 build_audio.py   # Allan：zh-TW-YunJheNeural +20%；阿拉蕾：zh-TW-HsiaoYuNeural +20%、+35Hz
python3 build.py         # 輸出 index.html（角色圖取自 ../isms-animation/assets/characters）
```
`index.html` 與 `audio/` 放在一起開啟。
