# ISMS 的一年（動畫）

Allan 顧問 × AI 小助手阿拉蕾，用約 7 分鐘、12 幕的動畫說明企業 ISMS 的日常、每月、每季、半年與每年工作，以及 15 項運作能力、資安事件應變、稽核員觀點與 ISMS 對管理者的價值。

製作：Allan Lo｜2026/10/16

## 使用方式

用瀏覽器開啟 `index.html`（角色圖已內嵌；配音檔在旁邊的 `audio/` 資料夾，兩者要放在一起）。

- 播放／暫停、上一幕／下一幕、拖曳進度條、0.8×–1.5× 速度、聲音開關
- 配音：Allan 顧問為台灣男聲（zh-TW-YunJheNeural，語速 +20%）；阿拉蕾為活潑俏皮的小女生（zh-TW-HsiaoYuNeural，語速 +20%、音高 +35Hz），與先前動畫課的配音設定一致
- 頁面下方「ISMS 工作速查表」依頻率列出表單編號、使用時機與是否為稽核必要紀錄

## 修改與重新產生

- 劇本台詞：`src/template.html` 內的 `SCRIPT` 物件
- 畫面版面：`src/template.html` 內各 `<section class="scene">`，`data-at="N"` 表示第 N 句台詞開始時出現
- 速查表資料：`src/template.html` 內的 `REF` 物件
- 角色圖：`assets/characters/*.webp`（由角色設定圖裁切去背）

修改台詞後依序執行：

```
pip install edge-tts
python3 build_audio.py   # 只重新產生有改動的台詞語音，並更新 src/timing.json
python3 build.py         # 內嵌角色圖與時間軸，輸出 index.html
```

朗讀發音要調整時（例如數字、英文縮寫），在 `build_audio.py` 的 `SAY` 加上替換規則，字幕不受影響。
