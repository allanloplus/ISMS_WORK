# ISMS 工作地圖（互動動畫）

同一個模擬年度（2027），用三種視角看 ISMS 的日常工作。Allan 顧問與 AI 小助手阿拉蕾在關鍵日期出來導覽並配音。

製作：Allan Lo｜2026/10/16

| 視角 | 畫面 | 看什麼 |
|---|---|---|
| 時間地圖 | 一年一圈的圓盤，由內到外：不定期、每天、每月、每季、半年、每年 | 什麼時候做什麼；每件工作化成紀錄飛進中央「紀錄庫」 |
| 工作流程 | 捷運路線圖：申請與變更、每日監控、資安事件、半年審查、每月量測、每季追蹤、年度 PDCA | 工作怎麼流動：核准 → 執行 → 歸檔 → 月報 → 管審 |
| 工作類別 | ISMS 15 項運作能力（A01–A15）區塊 | 哪一類工作在忙、每月工作量 |

頁面下方會列出「本月的 ISMS 工作」（依頻率分組、附表單編號）；點選站點或能力區塊可看詳細說明。

## 資料
- 每年、半年、每月：依「ISMS 文件清單及每月執行紀錄建議（12 月驗證版）」
- 15 項能力分類：依「ISMS 的 15 項運作能力之作業流程（2027）」
- 每季作業：Allan 顧問建議
- 不定期申請：依權重以固定亂數模擬（每次播放相同），件數僅供示意
- 7 月的勒索軟體事件為劇情示範

## 使用與修改
`index.html` 與 `audio/` 放在一起開啟。修改 `src/template.html`（`EV` 事件資料、`GUIDE` 導覽台詞、`ST` 流程站點）後：

```
pip install edge-tts
python3 build_audio.py   # 產生導覽語音（Allan：zh-TW-YunJheNeural；阿拉蕾：zh-TW-HsiaoYuNeural +35Hz）
python3 build.py         # 輸出 index.html（角色圖取自 ../isms-animation/assets/characters）
```
