# ISMS 大富翁：資安一年大挑戰（網頁桌遊）

1～4 人在同一台裝置輪流擲骰子，走完 ISMS 的一年。主持人是 AI 小助手阿拉蕾，稽核員是 Allan 顧問（皆有配音）。

製作：Allan Lo｜2026/10/16

## 棋盤（24 格，順時針）
- **起點／終點**：開局每人完成 1 月「年度啟動」（L4-17、L4-12）並有 3 預算；走回起點＝12 月底外部稽核。
- **月份任務格（2～12 月）**：依「ISMS 文件清單及每月執行紀錄建議」的年度工作；答題完成，獲得該月紀錄卡，答對加 ★。路過的月份可以花 1 預算補做。
- **日常申請**：15 張情境卡（新人報到、廠商進機房、防火牆規則、資料庫異動……），選對表單得卡＋★，選錯風險 +1。
- **資安事件**：12 張事件卡（勒索軟體、釣魚、離職帳號、供應商被駭……），有對應的防禦紀錄才擋得住，否則風險 +2。
- **每月月報**：情資 L4-45、KPI L4-18、月報、日誌審查；答對得卡並增加預算。
- **AI 小助手**：情資摘要、到期提醒補做、防護盾、預算。
- **Allan 稽核**：抽查一張「到目前為止應該要有」的稽核必要紀錄。

## 勝負
- 取得驗證：稽核必要紀錄覆蓋率 ≥ 60%（共 34 張），而且風險 ≤ 4。
- 計分：紀錄卡 1 分／張，必要紀錄再加 1 分，★ 1 分，風險每點扣 2 分。通過驗證者優先排名。
- 回合中可以投入 2 預算讓風險 −1。

## 修改
卡片資料都在 `src/template.html`：`CARD`、`MONTHS`、`DAILY`、`EVENTS`、`MONTHLY`；配音台詞在 `LINES`。

```
python3 build.py         # 輸出 index.html（角色圖取自 ../isms-animation/assets/characters）
```
